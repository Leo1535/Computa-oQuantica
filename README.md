# Computação Quântica: Algoritmo de Grover (Era NISQ)

Artefato prático desenvolvido para o Trabalho Semestral de Tópicos Avançados em Computação (Tema 03).
Este repositório contém a implementação do Algoritmo de Grover para 2 qubits utilizando o Qiskit, focado em demonstrar a aceleração teórica da busca (estado alvo |11>) e plotar o circuito e o histograma de resultados.

## 🛠️ Pré-requisitos
Para reproduzir este experimento localmente, você precisará do Python 3 instalado em sua máquina.

Instale as bibliotecas necessárias executando o seguinte comando no terminal:
```bash
pip install qiskit qiskit-aer matplotlib pylatexenc
